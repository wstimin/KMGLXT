# 宝塔面板安装

## 1. 准备运行环境

在“软件商店”安装 Node.js 版本管理器和 PM2 管理器，安装 Node.js 24。创建目录 `/www/wwwroot/kmglxt`，从 GitHub Releases 下载并解压最新 `KMGLXT-v*-panel.tar.gz`。面板专用包已经包含生产依赖，不需要打开终端执行 `npm install`。

## 2. 创建 Node 项目

- 项目目录：`/www/wwwroot/kmglxt`
- 启动文件：`server/app.js`
- Node 版本：24
- 端口：1111
- 运行用户需要对项目目录和 `server/data` 有写权限
- 开启崩溃自动重启

环境变量：

```text
NODE_ENV=production
PORT=1111
DATA_DIR=/www/wwwroot/kmglxt/server/data
TRUST_PROXY=1
DEPLOY_MODE=baota
WEB_UPDATE_RESTART=1
```

## 3. 域名与网页安装

在网站中添加反向代理，目标地址填写 `http://127.0.0.1:1111`，再由宝塔申请 HTTPS 证书。不要再运行 `km domain`，域名和证书全部交给宝塔管理。

打开绑定的域名，系统会自动进入安装向导。在页面中填写站点名称、超级管理员账号和密码，点击“完成安装并进入后台”即可。安装完成后安装入口自动关闭。

完成后，后台“部署与更新”页面可以显示 GitHub Release 新版本并执行更新。更新会先备份数据库，完成后退出 Node 进程，由宝塔的进程守护自动拉起。
