# 面板部署

这里的宝塔和 1Panel 安装方式与 `deploy/km.sh` 一键安装器分开：面板负责 Node 进程、域名、HTTPS 和反向代理，应用只管理自身文件与数据库。

- [宝塔安装](./宝塔.md)
- [1Panel 安装](./1Panel.md)

两种方式都使用 GitHub Release 中的 `KMGLXT-v*-panel.tar.gz`。专用包包含构建好的前端和生产依赖：上传解压、创建 Node 项目、绑定域名后，首次访问会自动打开安装向导，不需要先在终端初始化数据库。后台“部署与更新”页面会检查最新 Release，并在有新版时允许超级管理员直接更新。
